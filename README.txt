LEE JAPARIDZE — COMPLETE PORTFOLIO PACKAGE

FILES
- index.html: complete self-contained portfolio website.
- assets/: original project images used in the portfolio.

IMPORTANT
All images are already embedded directly inside index.html, so the site will display even if you upload only index.html.
The assets folder is included as a separate backup/source collection.

PUBLISH ON GITHUB PAGES
1. Open your portfolio GitHub repository.
2. Upload/replace index.html in the repository root.
3. You may also upload the assets folder to keep the original images alongside the site.
4. Commit the changes and wait for GitHub Pages to publish.

The Web Project preview links to:
https://japaridze-lee.github.io/Final/index.html

The embedded desktop preview depends on the target site allowing iframe embedding.
